# Ghost VPS Bot - Local Runtime

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run the bot:
```bash
npm start
```

## Features

- ✅ Runs Bots.Business exported code locally
- ✅ Persistent data storage (database.json)
- ✅ Admin system with dynamic configuration
- ✅ Channel management via `/setchannel`

## Admin Setup

After first run, use `/onersetup` to initialize your admin account.
